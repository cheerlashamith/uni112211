══════════════════════════════════════════════════════════════════════════════════
KEY FUNCTIONS IN supabase.sql
══════════════════════════════════════════════════════════════════════════════════
  mark_attendance(p_registration_id, p_scanner_id, p_scanner_name)
    - Returns { ok, reason, student_name, event_name }
    - Handles: already_marked, not_found, unauthorized
    - Roles allowed: coordinator, head_coordinator, volunteer, super_admin

  recalculate_event_slots(target_event_id)
    - Auto-updates events.slots.filled on every registration change

  sync_event_name_title()
    - Trigger: ensures events.name and events.title always match

  notify_event_created()
    - Trigger: inserts notification for all users when a new event is published

  get_user_role(uid)
    - Returns user role as TEXT for use in RLS policies
